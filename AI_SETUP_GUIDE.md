# 🤖 WebLLM AI Chatbot Setup Guide for GitHub Pages

## 🚀 Quick Setup

### **No Setup Required!**

**The AI chatbot works out-of-the-box with zero configuration!**

- ✅ **100% Free** - No API keys, no signup, no costs
- ✅ **Runs locally** - AI model loads in your browser
- ✅ **Works offline** - Once loaded, no internet needed
- ✅ **No rate limits** - Unlimited conversations

### **How It Works**

**WebLLM** runs **TinyLlama-1.1B** directly in your browser with smart pre-caching:
- **TinyLlama-1.1B** - Smallest official WebLLM model (700MB)
- **Pre-cached loading** - Model downloads in background when page loads
- **Instant chat access** - AI ready immediately after pre-loading
- **Comprehensive knowledge** of Lord Reinier's complete background
- **Privacy focused** - conversations never leave your device

### **Step 1: First Time Setup**
```bash
npm run dev
# Visit: http://localhost:5173/portfolio/
# First visit: Wait 30-90 seconds for fast AI model to download and load
# After loading: AI works instantly for all future visits
```

### **Step 2: Deploy to GitHub Pages**
```bash
npm run build
# Upload dist/ folder to GitHub Pages
# Visitors will experience the same loading process
```

## 🚨 **Loading Process**

**Page Load (Background):**
- 🔄 TinyLlama pre-loads automatically when page opens
- 📊 Progress logged to console (silent to user)
- 🕐 Takes 30-45 seconds for 700MB model

**Chat Opening:**
- ⚡ **Instant!** If pre-loaded successfully
- 💬 AI responds immediately to questions
- ✅ "Local AI Ready" shows in header

**If Pre-load Fails:**
- ⏳ Quick on-demand loading (30-45 seconds)
- 📊 Progress shown: "TinyLlama: 67% (~15s)"
- 🚀 Then instant responses
